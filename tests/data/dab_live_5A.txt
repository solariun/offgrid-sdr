#  What this file does
#  -------------------
#  The record of a live check of dec::DabDecoder (src/decoders/Dab.h): a
#  NESDR SMArt v5 (R820T) on the project's own driver (src/rtlsdr, src/usb),
#  2.048 MS/s, gain 40 dB fixed, centred on channel 5A (174.928 MHz) in the
#  Netherlands (Eindhoven region), 40 s, with selectService(8023) at 16 s.
#  Lines: status every 4 s (frames, FIBs ok/read, DAB+ super frames ok/bad,
#  Reed-Solomon bytes fixed, audio units with good / bad CRC), the decoder's
#  text (ensemble, station list, station chosen, DLS) and the final list.
#  Run 1 without liboffgrid-codecs (audio units only); run 2 the same with
#  the codecs built in (HE-AAC v2 to PCM: seconds of sound and its rms at
#  the end; Glow FM is 32 kHz, KempenFM 48 kHz).  Of the other
#  channels tried (5C 6A 6B 7D 8A 11C 12C, at 30 and 42 dB) none locked
#  here: a Band III scan with this antenna showed a block only on 5A.
#
#  How it fits in
#  --------------
#  Made with a scratch tool (not in the repository) that feeds the stick's
#  IQ to processIq(); kept as evidence for the port.
#
#  Contributing
#  ------------
#  Add new live runs as new dab_live_*.txt files with the same header.
# ============================================================================
